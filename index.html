Pure Gym

A gym management web application built with React. Users can browse a catalog of gym classes, view detailed records, and — once authenticated — create, edit, and delete their own classes and comments. Built around React Router, context-based auth, and a REST API backend.

  • Full CRUD for authenticated users
  • Comments & user interaction
  • Guest vs. authenticated user roles
  • Client-side routing & auth guards
  • Custom hooks & service layer

Vanilla JS · SPA

Quiz Fever

A modular single-page application for creating, browsing, solving, and managing interactive quizzes. Built with plain JavaScript using lit-html for templating and page.js for routing, and integrated with Back4App (Parse Server) for authentication, quiz storage, and solution tracking.

  • Register / login with session persistence
  • Browse, search & filter quizzes
  • Interactive question-by-question contest mode
  • Results summary & wrong-answer review
  • Quiz editor — create & manage questions
  • Public profile pages & statistics
